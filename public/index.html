Start your Shelfwise server

This website shows the reports, but the data comes from the Shelfwise server running in Docker on your computer. Start it, then press Retry.

docker compose up -d

If Chrome or Edge asks to allow access to devices on your local network, choose Allow. That is how this page reaches your computer.

Your SalesDiary token is sent only to the Shelfwise server on your own computer.
